# UI の決まり（Shopee Smart Reply・WA Smart Reply・Zalo Smart Reply・Viber Smart Reply 共通）

2026-10-25 本人「おすすめどおり、1〜4と7・8・10を直して。5は押した回数を数えてから、6は試してからでいい。WA にも同じ決まりを当てて」。
もとのレビュー：Obsidian `10_shopee/Smart Reply UIレビュー_2026-10-24.md`（番号はそのノートの番号）。
見積もりカードの決まりは同じフォルダの `quote-card-spec.md`。

## 1. 1つの機能は1つの画面（UIレビュー 4）
- 引き出しのツール1つ＝見出し1つ＝中身1つ。**別のツールの画面の中に物を差し込まない**。
- 新しい物は、自分のツールを作るか、本人に置き場所を聞く。
- 例：仕入れ予定のリンクは 💴 見積もりの画面だけ（AI 候補・定型文・返し忘れには出さない）。見積もりカードは 💴 の画面だけ。
- 同じ物を2つのツールに並べて出す作り（表示の条件に別のツールの画面を2つ以上並べる）をしない。

## 2. 数字の札には名前を常に出す（UIレビュー 2）
- 札の意味をマウスを乗せた時の吹き出し（title）だけにしない＝「押さないと出ない・開かないと見えない」を作らない。
- 札の下（または横）に2〜4字の名前（未返信・未読・返信時間・エラー など）。
- 毎日見ない物は「もっと」へ。数字が 0 の札は**消さずに薄くする**（WA も同じ・10/25 03-22 の相談に答えた）。
- 札の表示と吹き出しの中身を合わせる（例：中身が「直近7日に失敗 8件」なら表示も失敗の件数）。

## 3. 「未返信」は1つの画面（UIレビュー 3）
- 返していない会話は「📮 未返信」の1画面にまとめ、中のタブで「未返信／暫定返信／7日経過」を切り替える。会話を1件ずつ開いて探す「全件確認」は、その画面の中のボタン。
- 未返信の正は会話ログから作る 📮（chat_unanswered）。画面の未読バッジや巡回は補助。

## 4. 色の意味（UIレビュー 7・9）
- 赤は本当に失敗した時だけ。入力を待っている状態（「探す品名を入れて ↻」など）は灰色の案内。
- 入力欄の枠：**空は入力待ち＝灰色の点線**。**誤り（例：英語の商品名に日本語）だけ赤枠**。quote-card-spec 8.2・8.3 の「空なら赤枠」は 12-10 でこれに置き換えた（10/25 03-22 の相談に答えた）。
- オレンジ＝Shopee の色（見出し）、赤＝失敗、緑＝送る準備ができた、灰＝案内。※色の付け替え（9）：見積もりカードの「入力欄へ入れる」は 2026-11-04 本人「よろしく」で緑に決定（SR 6.19.73・WA と同じ #25d366 の塗り・白い字）。
- 定型文などの「📥 挿入」「🈂 入力欄へ入れる」も、入力欄へ入れるボタンなので同じ緑（#25d366・白い字）にそろえる（2026-11-06 03 の決め・4つの道具とも。Zalo の全体レビューで SR は青・WA と Zalo は橙とずれていた）。

## 4.5 💴 見積もりの始め方（10/25 03-22 の相談に答えた・SR の形）
- 見積もりの入口は**右端の 💴 ボタン1つ**。押すと 💴 の画面を開いて、「仕入れ予定の行（額あり）→ 前の見積もり → お客さんの発言」の順で始める（quote-card-spec 12-2）。
- 💴 の画面の中にあるのは、カード（↻ 計算し直す・📌／🔎 探し直す・🔎 お客さんの発言から新しく探す）と、その下の「🛒 仕入れ予定のリンク（この人）」の欄（行ごとの 💴 見積もり・🛒 Request page へ・足す・直す・消す）。
- **AI 候補・定型文など、ほかのツールの画面に見積もりの入口や仕入れ予定の欄を置かない**（1 の決まり）。WA で右端のボタンが無い作りなら、💴 の画面のいちばん上に「💴 この会話で見積もりを作る」を1つ置く形でよい。

## 5. 勝手に開く物・消えない通知（UIレビュー 8）
- 自分から開く小窓は「何か見つかった時だけ」開く。見つからなかった結果は、ボタンの小さな印だけ（押せば開く）。
- 通知は、押す場所（どのボタンか）を書くか、要らなければ出さない。自動で済んでいることを手でやれと言う通知は出さない。

## 6. 文字の大きさ（UIレビュー 1・10）
- 本文・案内・ボタンは 11px 以上。注記だけ 10.5px まで。**10.5px より小さい字は使わない**（9px・10px も使わない）。
- 右端のボタンの名前は 11px・2行まで（「過去の答え」が2行で入る）。
- 入りきらない時に字を縮める処理も、10.5px より小さくしない。

## 7. ボタンを押した回数を数える（UIレビュー 5）
- 並び替えは推測でしない。ボタンごと・日ごとに押した回数を GM に数え（30日）、1週間分を見てから本人と決める。
- Shopee Smart Reply：GM `sar_tap_counts` ＝ { 'YYYY-MM-DD': { ボタンのid: 回数 } }。ページから `postMessage({ sarTapExport: 1 })` → `<html data-sar-tap-export>` で読める。

## 8. 機械の点検
- Shopee Smart Reply：`~/Documents/Claude/Projects/shopee作業/sr-ui-check.py <userscript>` で、10.5px より小さい字・右端のボタンの字・1つの表示を2つのツールに出す書き方を数える（NG が出たら直してから配る）。
- 見ているのは書き方の形だけ。差し込みの全部は見つけられない（目でも確かめる）。

## 9. 道具が埋められる値で止めない（2026-11-06 本人の決め）
本人「なんでさ、ラクにするのが目的でこのツール作ってるのに、一手間食わせるの？」（SR のまとめ買いの見積もりが「品物ごとの英語名を入れてから ↻」で止まった件・事業本部経由）。
- 道具が自分で作れる・推せる値（英語の商品名・重さ・目標の粗利の既定・カテゴリなど）が空の時に、「入れてください」で止めない。自動で埋めて先に進む。
- 自動で埋めた値には「自動」の印を付け、その場で直せるようにする。本人が直した値は「指定」とし、道具は上書きしない。
- 止めてよいのは、間違えるとお金やお客さんに響く物だけ。例：
  - 写真が無いのに出品する。
  - 為替が既定のレートのまま値段を出す。
  - VN の上限を超える。
  - 別の人の会話に入れる。
  - 二重に出品する。
  - 合意の額と違う額で足す。
- 止める時は、理由と、次に押す物を1つ添える（4. の色・5. の決まりのまま）。
- 4つの道具（SR・WA・Zalo・Viber）で同じにする。

## 10. 定型文の書き出しは本題から（2026-11-06 本人の決め）
本人「Good question! これ不要ですね」「他の定型文にもあったけど」「聞かれて送る場合と、そうじゃない時あるので」。
- 定型文の頭に「Good question!」「Great question」のような、質問された前提の言葉を書かない。文の頭はすぐ本題から。
- 新しく足す定型文も同じ。4つの道具（SR・WA・Zalo・Viber）で同じ。

## 12. 絞り込みの帯の作り方（2026-11-07 本人「ここも見にくいんだよな」・ポータル 👣 アクセス（各国）のグラフの上の5行）
- ふだんは「いま」の1行だけを出す（例「🌏 すべての国・訪問者・1か月（1日ごと）・📈 折れ線・前の期間を重ねる」）。「⚙ 変える ▸」で開く。開いた・閉じたは端末に覚える（ポータルは smdTaFold）。
- 開いた時：
  - 1つだけ選ぶ物（期間など）は1行の区切りボタン（つながったボタン）。
  - 2択（国ごと／アカウントごと など）は2つの切り替え。
  - 店は国ごとにまとめる（国旗＋国の名前の横に「本店／2店舗目／両方／なし」の選択欄）。店の数だけ丸を並べない。
  - 指標は、よく使う4つ（訪問者・ページビュー・注文数・売上）を出し、残りは「その他 ▸」。
  - グラフの種類はアイコンだけの小さなボタン（名前は title に）。
  - 重ねる物・足す物（7日移動平均・前の期間を重ねる・国ごとに分けて並べる）は ☑ の切り替え。
- ラベルの列（期間・単位…）の幅を揃える（44px）。ボタンの高さ（26px）・字（11.5px）・間隔を揃える。
- 保存している設定の意味は変えない（帯の形を変えても、前に選んだ物がそのまま効く）。

## 13. 長い表の見出しは固定（2026-11-07 本人「スクロールしたら列名がきえる」）
- 行が画面より長くなる表は、見出しの行を position:sticky で上に残す。上の固定の帯の高さ（ポータルは --smd-bar-h）の分だけ下げて止め、背景を付けて下の行が透けないようにする。
- 横スクロールの箱（overflow:auto）に入れると止まらない。箱で囲む時は箱の中で縦にもスクロールさせる（ポータルの .pf-scroll・.pf-table の形）。
- ポータルで同じ作りの物：.pf-table（.pf-scroll の中）・🏆 .prk-tbl・出品管理の見出し・👣 アクセスの商品の表（.ta-ptbl）。
